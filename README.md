## Repository Structure

### For Real VM / Multi-Server Setup:
- background-apache1.sh → Install Apache on Server 1
- background-apache2.sh → Install Apache on Server 2  
- background-apache3.sh → Install Apache on Server 3
- background-haproxy.sh → Install HAProxy
- background-jmeter.sh  → Install JMeter

### For Killercoda (Single Node):
- background.sh → All-in-one setup script
                  Simulates multi-server using ports
